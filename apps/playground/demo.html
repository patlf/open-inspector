Open Inspector

Inspect any page without handing over your browsing.

Every other page inspector asks to read and change your data on all websites. This one asks for nothing — no host permissions, no network requests, no account. That is not a promise in a readme; it is a check that fails the build.

What it reads

Layout anatomy

How the element lays out its children, how its parent places it, and the spacing scale the page actually follows.

Real typography

The font that rendered, measured on canvas rather than read off the stack, with full metrics and the modular scale behind them.

Colour and contrast

A palette clustered in OKLab, live WCAG grading, and a page-wide audit that finds every failing pair.

What it asks for

NO SITE ACCESS

The manifest requests activeTab and scripting, and declares no host permissions at all. Chrome's own install screen will tell you the same thing.
