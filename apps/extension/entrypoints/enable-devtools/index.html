Open Inspector in DevTools

Adds an Open Inspector tab to Firefox DevTools, next to the Inspector. The panel shows there instead of over the page, and follows the element you select in the Inspector.

Firefox asks for the devtools permission first, in its own words: “Extend developer tools to access your data in open tabs.” Nothing is sent anywhere either way, and the inspector still reads a page only while you have it running there.

Checking…

After turning it on, close and reopen DevTools to see the tab.
